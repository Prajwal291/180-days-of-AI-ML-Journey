A structured, zero-to-pro log of my AI/ML specialization — built alongside my DSA and Core CS placement prep. Following a six-stage path from Python basics to build-ready AI/ML skills.

## 🧭 Why This Repo Exists

I'm learning in public — committing real exercises and projects as I build them, not just posting finished work. This repo is the running record of that process.

---

## 🗺️ The Roadmap — Python for AI

| Stage | Topic | What It Covers |
|---|---|---|
| 1 | Basics | Variables, data types, conditions, loops, functions, strings |
| 2 | Structures + OOP | Lists, dicts, sets, tuples, comprehensions, classes, `try/except`, file I/O, modules |
| 3 | NumPy | Arrays, broadcasting, vectorized operations, matrix multiply |
| 4 | Pandas | DataFrames, `read_csv`, filtering, `groupby`, cleaning real data |
| 5 | Plots + Notebooks | Matplotlib, Seaborn, Jupyter, Google Colab |
| 6 | Build | Real projects — beginner → intermediate → AI-flavored (Titanic EDA, spam classifier) |

**The rule:** one hour of typing for every hour of watching. Learn something, build something, get stuck, fix it, repeat.

After Python for AI: **ML Fundamentals → LLM/GenAI → AI Agents.**
